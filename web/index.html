Shusha network lab

Shusha machines running in your browser, each an x86-64 PC emulated by QEMU compiled to WebAssembly. They share one virtual Ethernet segment, so the Workspace, its encrypted channels and co-editing in Qələm work between them. Nothing leaves your browser.

Each machine opens in its own window. Open two or three, then arrange them side by side. Each needs about 600 MB of memory and one CPU core.

    Try the Workspace between machines

    1. On each machine, create the administrator account (any name, a password of 8+ characters). Each machine is a separate PC with its own keys. This is a live session: reloading the page wipes it.
    2. On machine 1, open the Workspace app from the dock (the purple icon), create a workspace, then press Invite someone. The invite code appears above.
    3. On machine 2, open the Workspace app, click into the invite code field, and press Type machine 1's invite on machine 2's toolbar (or copy it and paste with Ctrl+V into its screen). Then enter a name and press Join.
    4. Open Qələm on either machine, write something, and save it into the workspace. The other machine receives it. Ranks decide who may read or edit without asking.
    5. Type a word from your file into Is this text on the wire? below. It should never be found, because everything between machines is end-to-end encrypted.
